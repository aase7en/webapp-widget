แผน 2 — โครงข้อมูล Google Sheet Backend

Backend เดียวที่ได้รับอนุมัติคือ Google Sheet API Report_PM2.5 และ Apps Script ที่ผูกกับชีตนั้นอยู่แล้ว ตารางด้านล่างเป็นสเปก/แนวคิด ไม่ได้สร้างชีตใหม่หรือเปิด Trigger เพิ่ม

ชีตฟิลด์หลักใช้ทำอะไร
Station Config (เสนอ) station_id, name_th, label_short, bank_level_m, watch_level_m, critical_level_m, normal_label, watch_label, critical_label เก็บ config ต่อสถานี เพื่อคำนวณ % ระดับตลิ่ง และตัดสินสถานะ ปกติ / เฝ้าระวัง / วิกฤต
Water_Level_History observed_at, station_id, level_m, delta_m, source ใช้วาดกราฟย้อนหลัง 7 วัน และแสดงการเปลี่ยนแปลงล่าสุด
Latest Snapshot (เสนอ) station_id, level_m, delta_m, updated_at, status, percent_of_bank, animation_band ค่าใช้งานเร็วสำหรับหน้า widget โดยไม่ต้องคำนวณซ้ำทุกครั้ง
Widget Config (เสนอ) trend_days, clock_format, display_order, fallback_level_band ตั้งค่าหน้า widget และค่า fallback

ใช้ Script/Trigger เดิมเท่านั้น — ตารางเวลาให้ตรวจจากระบบจริง เก็บประวัติย้อนหลังเพื่อกราฟ 7 วัน การจับคู่ % กับฉากเป็น DEMO เท่านั้น; ไม่ใช่ % เปิดประตูจริง
