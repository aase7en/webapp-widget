## Risk communication provenance
There is **no universal single air-temperature value** meaning
'no danger' for every person. For hot conditions, display-only advice
uses approximate US NWS Heat Index ranges (air temperature + humidity)
converted 80/90/103/125°F to 26.7/32.2/39.4/51.7°C.
Cold clothing advice below 16/20°C is editorial comfort guidance,
**not** an official global hazard standard.

Official references:
- NWS: https://www.weather.gov/ama/heatindex
- WHO 31 July 2026: https://www.who.int/en/news-room/fact-sheets/detail/climate-change-heat-and-health
- CDC: https://www.cdc.gov/heat-health/about/index.html

## Invalid humidity and fallback review
- Humidity used for calculated heat guidance must be finite and between
  0% and 100%. Otherwise the widget uses conservative temperature-only
  advice and does not create an NWS Heat Index or existing Heatstroke warning.
- QA includes synthetic 300% humidity, which is not a real sensor value.
- Browser QA checks two fallback modes: physically implausible four-digit
  number and plausible hot-weather upper/lower badges remaining separate.
